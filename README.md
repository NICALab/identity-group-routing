# identity-group-routing
Official code base for Neuronal Identity as an Organizational Basis for Analyzing Neural Population Dynamics @ NeurIPS 2026

## Project page

https://nicalab.github.io/identity-group-routing/

The placeholder page lives in `docs/index.html`. The GitHub Actions workflow in
`.github/workflows/pages.yml` publishes `docs/` when changes are pushed to `main`.

For the first deployment, enable **Settings → Pages → Build and deployment →
Source → GitHub Actions** in the repository, then push these files to `main`.
Subsequent changes to the page deploy automatically. You can also run the
**Deploy project page** workflow manually from the Actions tab.
